# 附录 A: 术语表

> **本指南核心术语定义**

---

## A

**Active Perception (主动感知)**
- Agent 主动选择感知内容,而非被动接收所有信息
- 包括: 选择性注意、扫视控制、目标导向感知

**Agent (智能体)**
- 能够感知环境、做出决策并执行行动的自主实体
- 核心特征: 自主性、反应性、主动性

**Autonomy (自主性)**
- 自我决定、自我行动的能力
- 三个要素: 独立性、主动性、持续性

**Autonomous Agent (自主智能体)**
- 能在没有外部持续干预下运行的 Agent
- 目标: 从 Level 0 (被动) 到 Level 4 (完全自主)

---

## B

**Belief State (信念状态)**
- Agent 对世界状态的认知
- 包含: 不确定性、置信度、概率分布

**BuildBlock (构建块)**
- 可组合的 Agent 组件
- 特点: 统一接口、标准化、可复用

---

## C

**Constitutional AI (宪法 AI)**
- 内置"宪法"约束的 AI 系统
- 特点: 不可违反的原则、自我审查、自动修订

**Curiosity (好奇心)**
- 对信息增益的追求
- 实现: 惊讶度驱动、信息增益驱动、新颖性检测

**Collective Intelligence (集体智慧)**
- 多 Agent 系统涌现的智能
- 表现: 协作、分工、规范、文化

---

## D

**Decision System (决策系统)**
- Agent 选择行动的核心模块
- 类型: 慎思式、反应式、自主式、混合式

**Deliberative Decision (慎思式决策)**
- 基于推理和规划的决策
- 特点: 深度思考、向前模拟、最优选择

**Dual Process Theory (双重过程理论)**
- 思维分为快速(系统1)和慢速(系统2)两个系统
- 启发: Agent 设计中结合两种决策模式

---

## E

**Embodiment (具身)**
- Agent 有"身体"与环境互动
- 重要性: 真实因果学习、 grounded cognition

**Episodic Memory (情景记忆)**
- 存储具体事件和经历
- 特点: 时空标记、感官细节、自传性

**Event-Driven Loop (事件驱动循环)**
- 由事件触发的运行模式
- 优点: 快速响应、资源高效
- 缺点: 被动性

**Exploration (探索)**
- 主动寻找信息和新体验
- 策略: 随机、ε-贪婪、好奇心驱动

**Explainability (可解释性)**
- Agent 行为可被理解和解释
- 类型: 事后解释、可解释模型、可视化

---

## F

**Free Energy Principle (自由能原理)**
- 生物系统最小化自由能(惊奇)
- 启发: 产生主动探索和行动

**Fully Autonomous Agent (完全自主智能体)**
- Level 4 自主性,可自主定义存在意义
- 当前: 理论阶段

---

## G

**Goal (目标)**
- Agent 期望达到的状态
- 层级: 元目标 → 主目标 → 子目标 → 行动

**Goal Generation (目标生成)**
- Agent 自主创建目标的能力
- 驱动: 环境、知识、价值

**Generalization (泛化)**
- 从具体经验中提取抽象知识
- 方法: 归纳、类比、规则提取

---

## H

**Hybrid Runtime (混合运行模式)**
- 结合事件驱动、轮询、自主探索
- 优点: 平衡响应性和主动性

**Hierarchical Decision (分层决策)**
- 战略 → 战术 → 操作 → 执行
- 优点: 处理复杂长期目标

---

## I

**Intrinsic Motivation (内在动机)**
- 源于系统内部的驱动力
- 类型: 好奇心、成就感、生存需求

**Information Gain (信息增益)**
- 新信息带来的知识增量
- 计算: KL 散度、熵减

**Integrated Information Theory (IIT)**
- 意识的数学理论
- 核心概念: Φ (整合信息)

---

## M

**Memory System (记忆系统)**
- Agent 存储和检索信息的机制
- 类型: 工作、情景、语义、元认知

**Metacognition (元认知)**
- 对自己认知的认知和控制
- 组成: 元认知知识、调节、体验

**Meta-Learning (元学习)**
- 学习如何学习
- 方法: MAML、Reptile、学习初始化

**Motivation System (动机系统)**
- 产生和调节驱动力
- 组成: 好奇心、成就感、生存需求

**Multimodal Fusion (多模态融合)**
- 结合视觉、听觉、文本等信息
- 方法: 早期融合、晚期融合、注意力融合

---

## N

**Neural Correlates of Consciousness (NCC)**
- 意识的神经相关性
- 特征: 全局工作空间、长程同步、γ 波段

**Novelty Detection (新颖性检测)**
- 识别前所未见的信息
- 方法: 相似度计算、密度估计

---

## O

**OpenClaw**
- 优雅的 Agent 部署方案
- 特点: 一键安装、Docker Compose、CLI 向导

**Optimality (最优性)**
- 决策在某种标准下是最好的
- 类型: 帕累托最优、纳什均衡

---

## P

**Proactiveness (主动性)**
- 不等外部触发,主动寻找并行动
- 层次: 响应式主动、探索式主动

**Polling Loop (轮询循环)**
- 定期检查状态的运行模式
- 优点: 简单可靠
- 缺点: 资源消耗

**Predictive Model (预测模型)**
- 预测行动后果的世界模型
- 用途: 规划、好奇心评估、决策

---

## R

**ReAct Loop**
- 推理(Reasoning) + 行动(Act)循环
- 模式: Thought → Action → Observation

**Reinforcement Learning (强化学习)**
- 从奖励信号中学习最优策略
- 类型: 值迭代、策略梯度、Actor-Critic

**Reflexive Decision (反应式决策)**
- 基于刺激-响应的快速决策
- 特点: 无意识、自动化、低延迟

---

## S

**Semantic Memory (语义记忆)**
- 存储知识和概念
- 特点: 抽象、去情境化、命题性

**Self-Model (自我模型)**
- Agent 对自己能力的认知
- 重要性: 准确的自我评估

**Swarm Intelligence (群体智能)**
- 简单个体产生的集体智能
- 示例: 蚁群、蜂群、鸟群

**Synthetic Motivation (合成动机)**
- 人工设计的内在动机系统
- 组成: 好奇心 + 成就感 + 生存需求

---

## T

**Theory of Mind (心智理论)**
- 理解他人有信念、欲望、意图
- 重要性: 社交协作、欺骗、沟通

**Transfer Learning (迁移学习)**
- 将知识从一个任务应用到另一个
- 类型: 归纳、基于样本、 无监督

---

## V

**Value Alignment (价值对齐)**
- Agent 目标与人类价值一致
- 方法: 宪法 AI、价值学习、逆强化学习

**Visual Attention (视觉注意)**
- 选择性地处理视觉信息
- 类型: 自底向上(显著性)、自顶向下(目标导向)

---

## W

**Working Memory (工作记忆)**
- 当前关注的信息缓存
- 容量: 有限 (~7项)
- 功能: 临时存储、认知操作

**World Model (世界模型)**
- Agent 对环境的内部表示
- 用途: 预测、规划、反事实推理

---

## Z

**Zero-Shot Learning (零样本学习)**
- 无需训练即能处理新任务
- 方法: 元学习、大模型提示
